# SG National Events & Leadership Monitor

Version 1.0 — Developed by Desmond Song.

Public-information dashboard covering Singapore's leadership, MHA, MINDEF, MFA, METI, Parliament and major events.

## Status
Frontend deployed to repository. Live data ingestion, automated monitoring and social media feeds are not yet implemented. The event feed starts empty to prevent invented announcements.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root).

## Safety
Publicly announced events only; no real-time movement tracking. Verify all announcements with official sources.
